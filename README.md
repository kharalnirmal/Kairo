# ⏳ Kairo

**Kairo** is a minimal focus timer for deep work.  
It’s a personal project built to support focus during low-motivation days.

---

## 🎯 Goal

The goal of Cairo is simple:
- encourage focused work sessions
- reduce distractions
- keep productivity calm, not overwhelming

It’s designed to be quiet, intentional, and easy to use.

---

## 🛠 Tech Stack

- ⚛️ React  
- 🎨 Tailwind CSS  
- 🧩 TypeScript  

Only essential tools are used to keep the project clean and maintainable.

---

## 📝 Notes

- Built with a minimal design philosophy  
- Focused on clarity over features  
- Created as a personal learning and focus project
